# Wylsacom VK Engagement Analysis

Анализ 5000 публикаций сообщества Wylsacom во ВКонтакте.

Исследовалась связь вовлечённости аудитории с:
- форматом публикации;
- тематикой;
- временем суток;
- днём недели;
- длиной текста;
- интервалом между публикациями.

Вовлечённость рассчитывалась в пересчёте на 1000 просмотров.

## Files

- `collecting.py` : сбор данных через VK API
- `analysis.py` : обработка, анализ и визуализация
- `wylsacom.csv` : подготовленная выборка
- `wylsacom_analysis.xlsx` : результаты в Excel
